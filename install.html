Install guide

ثلاث خطوات وتصبح لعبتك بالعربية. لا تحتاج أي برنامج إضافي، ولا يُعدَّل أي ملف من ملفات اللعبة.

Three steps and your game speaks Arabic. No extra programs needed, and no game files are changed.

هذا شرح عام. لكل لعبة خطوات خاصة في صفحتها (تبويب «طريقة التثبيت»)، والأمثلة هنا من Slay the Spire 2.

This is a general guide. Each game has its own exact steps on its page (the "Install steps" tab). The examples here use Slay the Spire 2.

00

حمّل الترجمة وفك الضغط

Download and unzip

من صفحة اللعبة اضغط زر «تحميل الترجمة». سيصلك ملف .zip.

اضغط عليه كليك يمين ← Extract All… (استخراج الكل). سيظهر مجلد باسم المود، مثل ArabicTranslation.

On the game's page, press "Download translation". You'll get a .zip file.

Right-click it → Extract All…. A folder with the mod's name appears, like ArabicTranslation.

  • ArabicTranslation-v0.1.0.zip
  • ArabicTranslation
01

افتح مجلد اللعبة من Steam

Open the game folder from Steam

  1. افتح Steam واذهب إلى Library (المكتبة).
  2. اضغط كليك يمين على اسم اللعبة.
  3. اختر Manage ثم Browse local files.

سيفتح لك Windows مجلد اللعبة مباشرة، وعادةً يكون في:
C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2

  1. Open Steam and go to your Library.
  2. Right-click the game's name.
  3. Choose Manage, then Browse local files.

Windows opens the game folder for you. It's usually here:
C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2

02

ضع المود في مجلد mods

Put the mod in the mods folder

داخل مجلد اللعبة ابحث عن مجلد اسمه mods. إن لم يكن موجودًا فأنشئه: كليك يمين ← New ← Folder، وسمّه mods بأحرف صغيرة.

انسخ مجلد المود كاملًا إلى داخل mods. يجب أن يكون ملف .json داخل مجلد المود مباشرة، كما في الشكل.

Inside the game folder, look for a folder named mods. If it doesn't exist, create it: right-click → New → Folder, and name it mods in lowercase.

Copy the whole mod folder into mods. The .json file must sit directly inside the mod folder, like in the picture.

خطأ شائع: مجلد داخل مجلد بنفس الاسم (ArabicTranslation\ArabicTranslation\…). إن حدث هذا فانقل المجلد الداخلي مستوى واحدًا للأعلى.

Common mistake: a folder inside a folder with the same name (ArabicTranslation\ArabicTranslation\…). If that happens, move the inner folder up one level.

03

اختر العربية من الإعدادات

Pick Arabic in Settings

  1. شغّل اللعبة. في أول مرة قد تسألك اللعبة: هل تريد تفعيل المودات؟ اختر نعم.
  2. افتح Settings (الإعدادات) ← Language (اللغة).
  3. اختر العربية. هذا كل شيء، استمتع!
  1. Start the game. The first time, it may ask whether to enable mods. Choose Yes.
  2. Open Settings → Language.
  3. Choose العربية (Arabic). That's it, enjoy!

لم تظهر العربية في القائمة؟

Arabic isn't in the list?

  • تأكد أن المسار صحيح: mods\اسم_المود\اسم_المود.json.
  • تأكد أنك وافقت على تفعيل المودات عند تشغيل اللعبة.
  • تأكد أن إصدار اللعبة يطابق «إصدار اللعبة المختبَر» في صفحة الترجمة.
  • ما زالت المشكلة موجودة؟ اطّلع على الأسئلة الشائعة أو أخبرني على GitHub.
  • Check the path: mods\ModName\ModName.json.
  • Make sure you allowed mods when the game started.
  • Check your game version matches the "Tested game version" on the translation's page.
  • Still stuck? See the FAQ or tell me on GitHub.
