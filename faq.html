Short, honest answers to the questions I get most.

هل الترجمة آمنة؟

نعم. الترجمة نصوص عربية وخط فقط، ومعها في بعض الألعاب ملف كود صغير يخبر اللعبة بوجود لغة جديدة. لا يُعدَّل أي ملف من ملفات اللعبة، ولا تحتوي الترجمة على أي ملف من ملفات اللعبة الأصلية.

الترجمات لغوية فقط ولا تغيّر طريقة اللعب. وحمّل دائمًا من هذا الموقع (صفحة GitHub الرسمية للمشروع)، لا من مواقع أخرى.

ماذا يحدث لملف الحفظ (تقدّمي في اللعبة)؟

في بعض الألعاب مثل Slay the Spire 2، عند تشغيل أي مود تنقلك اللعبة تلقائيًا إلى ملف حفظ منفصل خاص بالمودات، فيبدو تقدّمك وكأنه صفر.

لا تقلق: تقدّمك الأصلي في أمان ولم يُمَس. يعود كما كان بمجرد تشغيل اللعبة بدون المود، لأن الملفين منفصلان تمامًا.

صدر تحديث جديد للعبة، ماذا أفعل؟

غالبًا تستمر الترجمة بالعمل. لكن التحديثات الكبيرة قد تضيف نصوصًا جديدة تظهر بالإنجليزية، أو قد تمنع المود من العمل مؤقتًا.

  • قارن إصدار لعبتك بـ«إصدار اللعبة المختبَر» في صفحة الترجمة.
  • إن صدر إصدار جديد من الترجمة فحمّله واستبدل المجلد القديم بالجديد.
  • إن توقفت اللعبة عن العمل، احذف مجلد المود مؤقتًا وانتظر التحديث، ثم أخبرني على GitHub.
كيف أزيل الترجمة؟
  1. غيّر لغة اللعبة من الإعدادات إلى أي لغة أخرى.
  2. أغلق اللعبة.
  3. احذف مجلد المود من داخل مجلد mods (مثلًا mods\ArabicTranslation).

هذا كل شيء. اللعبة تعود كما كانت تمامًا، لأن الترجمة لا تغيّر أي ملف آخر.

هل الترجمة مجانية؟

نعم، مجانية بالكامل وستبقى كذلك. إن أعجبتك، فأفضل دعم هو أن تخبر أصدقاءك عنها وتبلغني عن أي خطأ تجده.

وجدت خطأ في الترجمة، كيف أبلغ عنه؟

افتح «Issue» جديدًا على GitHub (الرابط في أسفل الصفحة)، واكتب اسم اللعبة والنص الخاطئ واسم الشاشة أو البطاقة، وأرفق صورة إن أمكن. كل ملاحظة تساعد!

هل هذه ترجمة رسمية؟

لا. هي ترجمات معجبين غير رسمية، ولا علاقة لي بمطوري الألعاب أو ناشريها. إن أصدر المطوّر ترجمة عربية رسمية فهي الأفضل دائمًا.

Is it safe?

Yes. A translation is just Arabic text and a font, plus (for some games) a tiny code file that tells the game a new language exists. No game files are changed, and the download contains no files from the original game.

Translations only change text, never gameplay. Always download from this site (the project's official GitHub page), not from other sites.

What happens to my saves?

Some games, like Slay the Spire 2, automatically switch to a separate save whenever mods are on, so your progress looks like it reset.

Don't worry: your original progress is safe and untouched. It comes back as soon as you play without the mod, because the two saves are completely separate.

The game just updated. What now?

Usually the translation keeps working. But big updates can add new text (which shows in English) or stop the mod from loading for a while.

  • Compare your game version with the "Tested game version" on the translation's page.
  • If there's a new translation version, download it and replace the old folder.
  • If the game stops working, remove the mod folder for now, wait for an update, and tell me on GitHub.
How do I uninstall?
  1. Switch the game's language in Settings to any other language.
  2. Close the game.
  3. Delete the mod's folder inside mods (for example mods\ArabicTranslation).

That's it. The game is exactly as before, because the translation doesn't change any other file.

Is it free?

Yes, completely free, and it will stay that way. If you like it, the best support is telling your friends and reporting any mistakes you find.

I found a translation mistake. How do I report it?

Open a new "Issue" on GitHub (link at the bottom of the page). Include the game, the wrong text, and the screen or card name, plus a screenshot if you can. Every report helps!

Is this an official translation?

No. These are unofficial fan translations, not affiliated with the game developers or publishers. If a developer releases an official Arabic translation, that's always the best choice.
